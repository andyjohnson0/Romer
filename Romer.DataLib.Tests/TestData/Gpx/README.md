# GPX test data

These files were written by hand for Romer's tests. They aren't exports from any mapping app or service, and they're
covered by the repository's licence.

Coordinates are approximate positions of public landmarks, and names are place names. Elevations and times are made up.

| File | Tests |
|---|---|
| `malham-loop-route.gpx` | A route (`rte`) with named, elevated points and no metadata |
| `waypoints.gpx` | Waypoints (`wpt`) with metadata, times, descriptions, an XML entity, a non-ASCII character and a missing elevation |
| `track-two-segments.gpx` | A track (`trk`) whose points are split across two segments |
| `gpx-1.0.gpx` | The older GPX 1.0 format |
| `malformed.gpx` | Truncated XML |

Long tracks, for testing thinning, are generated by the tests rather than stored here.
